# WebStudio — HTML Markup

A WebStudio landing page created as part of the GoIT Full Stack Developer course.

**[Live Demo](https://andrii-mitko.github.io/goit-markup-hw-01/)**

## About the Project

This project demonstrates the fundamentals of semantic HTML5 markup through a business landing page for a digital agency.

The page presents the company's services, advantages, team members, and contact information.

## Features

- Semantic HTML5 structure
- Header with navigation and contact information
- Hero section with a call-to-action button
- Company advantages section
- Team members section with profile images
- Footer with company information
- Proper heading hierarchy
- Email and telephone links

## Technologies

- HTML5
- Semantic HTML
- Git
- GitHub Pages

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Andrii-Mitko/goit-markup-hw-01.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or build tools are required.
